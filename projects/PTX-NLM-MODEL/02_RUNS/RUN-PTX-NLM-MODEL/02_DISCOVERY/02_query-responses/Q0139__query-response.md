Synthesis and Key Implications
Evidence-Type Integration: All reported data from the three sources represent preclinical animal experimental findings ([PRECLINICAL]). Demonstrated cellular pathways—including phosphodiesterase-mediated downregulation of TNF-α, IL-1β, ICAM-1, and iNOS gene expression, along with microvascular cell-adhesion decongestion ([MECHANISM])—explain observed functional and structural protection.
