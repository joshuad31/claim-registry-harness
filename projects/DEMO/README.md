# SYNTHETIC DEMONSTRATION CORPUS

Every file in `sources/` is fabricated for the sole purpose of demonstrating that
the harness runs end to end from an empty folder. **None of it is real research,
and none of it may be cited as evidence about anything.** The study names, authors,
numbers and quotations are invented.

The domain was chosen because it is harmless and easy to read: whether a foliar
silicate treatment improves drought tolerance and grain yield in wheat. The
argument structure is deliberately mixed, so the harness has something to
separate:

- one greenhouse trial with a positive result;
- one multi-site field trial with a null result for yield;
- one review that reports mixed evidence and warns about transfer;
- one model-organism study that supplies a mechanism but not the field link;
- one field trial with a null yield result and a positive side finding.

The demo shows the machinery, not a conclusion. A real investigation would use a
real corpus.
