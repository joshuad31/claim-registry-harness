# How it differs from asking an AI

When you ask an AI a question, one model reads what it likes, weighs it out of sight and hands you a conclusion. You cannot see what it skipped, and it tends to follow the way you asked.

Claim Registry splits that job, so that no single model can do that:

- **One AI holds the sources and only answers narrow questions about them.** It never learns what you hope to show.
- **A second AI writes the questions.** It never sees the scores.
- **A third scores each answer against all the rival answers at once**, not only yours.
- **Every finding keeps its quotation**, checked word for word against the source file.

What comes out is a list of findings, each one traceable to a page and sorted by which answer it helps or hurts. You can check it yourself, and so can someone who disagrees with you.
